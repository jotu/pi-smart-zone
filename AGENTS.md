# Agent instructions

This repository is a [Pi](https://github.com/earendil-works/pi) extension developed with Pi and [Matt Pocock's skills](https://github.com/mattpocock/skills). Run `mise run check` before finishing any change.

## Agent skills

### Issue tracker

Local Markdown: specs and tickets live under the git-ignored `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, recorded as a `Status:` line in each ticket file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
